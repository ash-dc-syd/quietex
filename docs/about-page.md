# About page images

Open **Medusa → About page** to change the header photo independently of the homepage.

1. Choose **Upload header image**, or paste an HTTPS image URL.
2. Add an image description for accessibility. A landscape lifestyle photo works best.
3. Edit the heading, second heading line and short description if needed.
4. Review the image and text preview, then select **Save About page**. The saved header is published immediately.

Uploading alone does not publish changes. Leaving without saving prompts a warning. Use **Reload saved header** to discard unsaved edits.

Until a header image is saved, the storefront uses the existing homepage About image as a fallback. Once set, the About header image is independent. Body copy continues to use Website editor → About Quietex.

Under **Material section · panel photo**, upload or paste a panel photo and edit its description and caption. Select **Save About page** to publish. This updates the image beside “Made from PET felt.” without changing any product gallery images.

The header and material photo are stored separately from homepage content. Revision checks reject stale saves, and a shared metadata lock preserves other website and gallery settings.
