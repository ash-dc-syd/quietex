# Quietex website editor

Open https://medusa-server-production-456b.up.railway.app/app/website-editor and use your existing Medusa login. The sidebar also has **Website editor**.

1. Click a section in the left list or in the preview.
2. Change text, choose an existing image or paste an HTTPS image URL. For featured panels, select products by name.
3. Use the arrows to rearrange sections and checkboxes to show/hide them. Use Add section for an additional banner or another supported section.
4. Switch Desktop/Mobile to check the preview. Links inside the preview are disabled so you stay in the editor.
5. Save draft stores changes privately. Publish changes opens a confirmation and updates the website immediately. View website opens the published version.
6. Restore previous version returns both the draft and public homepage to the previous published version.

Changes are stored in the existing database and survive deployments. If another editor saves first, reload saved content before continuing; your work is not silently overwritten.

This editor covers homepage content and supported sections. Product content stays in Medusa Products. Header/footer layout, fonts and new section designs remain code changes. Images currently use hosted URLs; direct uploads and permanent media hosting are separate work. Quote buttons still open an email draft.
